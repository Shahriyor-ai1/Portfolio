# Shahriyor Qayumov — Shaxsiy sahifa

Qora va oltin uslubdagi bitta sahifali shaxsiy brend sayti: Three.js 3D sahna, 3D tilt kartalar va scroll animatsiyalari.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki lokal server bilan ishga tushiring:

```bash
python -m http.server 5500
```

## Tahrirlash

- **Rasm:** o'z rasmingizni `images/photo.jpg` nomi bilan joylang. Rasm bo'lmasa, "SQ" monogrammasi ko'rinadi.
- **Fikrlar:** `index.html` dagi `#testimonials` bo'limiga haqiqiy fikrlarni yozing.
- **Ranglar:** `style.css` boshidagi `:root` tokenlarida.

## Fayllar

| Fayl | Vazifasi |
|---|---|
| `index.html` | Sahifa tuzilmasi va matnlar |
| `style.css` | Dizayn, animatsiyalar, moslashuvchanlik |
| `script.js` | 3D sahna, tilt, hisoblagichlar, menyu, forma |
